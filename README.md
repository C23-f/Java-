# 城市社区15分钟生活圈便民设施评价与管理系统

## 📖 项目简介
本是一套前后端分离的GIS便民管理系统，基于SpringBoot + Leaflet + SQL Server开发。实现POI数据采集清洗、空间数据库存储、15分钟步行生活圈空间分析、小区可达性评分计算、地图可视化、后台数据管理与统计图表等功能，用于评估小区周边便民设施配套水平。

## 🛠 技术栈
- **前端**：Leaflet（地图）、ECharts（图表）
- **后端**：Java21、SpringBoot 4.0.8、MyBatis
- **数据库**：SQL Server2022（geography空间类型、空间索引）
- **数据处理**：Python，实现POI爬虫与数据清洗
- **协作工具**：Git/GitHub，VS Code，SSMS

## ⚡快速启动
1. 使用SSMS执行`init_db.sql`初始化数据库
2. 后端：JDK21+Maven，执行`mvn spring-boot:run`，端口9090
3. 前端：LiveServer启动，对接后端接口
4. 可选：运行python脚本完成POI采集清洗
