# webgis 实习

## 项目简介
小组WebGIS开发实习项目，淄博市张店区15分钟生活圈便民设施评价与管理系统。

## 仓库文件说明
- `日志/feishu-log.md`：**开发任务日志，所有任务记录写在此文件**
- `日志/开发日志填写规范.md`：日志书写规则，写日志前请务必阅读
- 其余文件夹：存放项目业务代码

## 协作要求
1. 完成任务后，在`日志/feishu-log.md`新增一条日志，新日志写在分割线下方最上方，旧日志不要删除。
2. GitHub提交：提交消息只写简短一句话，扩展描述留空。
3. 创建md文件时，文件名末尾必须带上`.md`后缀，否则不会渲染格式。
4. 多人编辑，不要两人同时修改同一个md文件，防止提交冲突。
