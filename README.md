# 城市社区15分钟生活圈便民设施评价与管理系统

**基于WebGIS的城市便民设施空间分析、可达性评分、用户评价与后台管理一体化系统**

本项目聚焦城市社区15分钟生活圈规划场景，依托高德地图GIS服务、SQL Server空间数据库与SpringBoot后端框架，实现小区与便民设施空间数据可视化、缓冲区可达性分析、用户评价管理、数据统计导出、智能分析等核心能力，是一套完整的前后端分离GIS空间分析管理系统。

## 📌 项目概述

系统以城市社区居住单元为核心，覆盖医疗、教育、商超、文体、生活、养老、交通七大类便民设施，结合空间缓冲区分析、点位聚合可视化、用户评价审核、数据统计可视化等功能，量化社区生活配套完善度，为15分钟便民生活圈规划、评估、优化提供数据支撑。

项目采用**前后端分离架构**，后端基于SpringBoot\+MyBatis\+SQL Server空间数据库，前端基于原生JS\+高德地图API\+ECharts，数据层基于Python爬虫采集真实POI数据、OSM路网数据，完成数据清洗、坐标纠偏与入库，实现从数据采集、处理、分析到可视化展示的全流程闭环。

## 🛠️ 技术栈

### 后端技术

- **核心框架**：SpringBoot 4\.0\.8、MyBatis 4\.0\.1

- **数据库**：SQL Server 2022（支持geography空间类型、空间索引、存储过程）

- **权限认证**：JWT令牌登录校验、角色分级权限控制（admin/operator/viewer）

- **工具依赖**：Apache POI（Excel导出）、JDK21、Maven 3\.9\.16

- **核心能力**：空间查询、缓冲区分析、动态SQL更新、全局异常处理、跨域配置、操作日志埋点

### 前端技术

- **核心能力**：高德地图JS API、WebGIS可视化、点位自定义渲染、网格聚合算法

- **基础技术**：原生HTML/CSS/JS、Element Plus、ECharts数据可视化

- **交互能力**：图层切换、框选查询、点位弹窗、平滑缩放、图表导出、Tab页面切换

### 数据层技术

- **数据采集**：Python Requests高德POI爬虫、OSM路网数据下载

- **数据处理**：GeoPandas空间清洗、GCJ\-02转WGS84坐标纠偏、数据去重降噪

- **数据格式**：CSV、GeoJSON空间矢量数据

## ✨ 核心功能模块

### 1\. GIS地图可视化模块

- 接入高德地图底图，完成地图缩放、平移、图层管理等基础能力

- 设施点位按行业规范配色：医疗红、教育蓝、商超橙、文体绿、生活紫、养老粉、交通青，配套专属Emoji图标

- 小区点位统一蓝色🏠图标，摒弃房价分色，界面更简洁统一

- 自研轻量网格聚合算法，替代不稳定官方插件，实现点位缩放动态合并/拆散，降低页面视觉杂乱度

- 支持点位弹窗详情、关键词检索、框选查询、一键清除绘制图形、点位平滑平移

- 精简页面冗余工具条，移除废弃绘图功能，优化界面交互体验

### 2\. 空间分析模块

- 15分钟步行缓冲区分析，自动统计范围内各类设施数量与分布情况

- 任意经纬度点位自定义缓冲区分析，支持地图任意点击实时空间统计

- 小区周边N米检索、矩形框选小区空间查询、全局模糊搜索（小区\+设施联合查询）

- 可达性评分智能计算，生成评分等级与分类明细，支持图表可视化展示与图片导出

### 3\. 业务数据管理模块

- **设施分类管理**：七大类设施完整CRUD接口，分类排序、数据筛选

- **小区/设施管理**：完整增删改查、参数校验、空间字段自动构建，支持按街道、房价、评分筛选

- **评价管理**：用户评价发布、个人评价查询、管理员审核，审核后自动联动更新平均分

- **收藏管理**：多类型资源收藏、防重复收藏、批量删除、收藏状态校验

- **分析方案管理**：全套CRUD接口，支持动态字段更新，持久化保存用户分析方案

- **街道行政区管理**：街道信息、边界GeoJSON查询，支持按街道筛选业务数据

### 4\. 数据统计与导出模块

- 多维度数据统计：设施类别数量、可达性评分分布、小区房价分布、TOP排行、区域汇总、视口密度统计

- 五大类Excel导出能力：小区列表、设施列表、评价报表、个人收藏、可达性分析结果

- 可达性分析结果动态图表渲染，支持图表图片本地导出

### 5\. 权限与日志模块

- 分级角色权限：admin超级管理员、operator运营人员、viewer普通访客，精细化接口权限控制

- JWT无状态登录认证，自动解析用户信息，接口请求统一携带Token鉴权

- 全业务操作日志埋点，记录增删改、评价审核等操作，支持分页查询与审计追溯

- 统一全局异常处理，接口异常、请求超时、权限拦截统一返回规范格式


## 🗄️ 数据库设计

系统共设计9张核心业务表，适配空间分析与业务管理全场景，通过`init_db.sql`脚本一键初始化，包含建库、建表、索引、视图、存储过程、测试数据全流程：

- **sys\_user/sys\_role**：用户、角色权限表，支撑登录鉴权与角色分级

- **district**：街道行政区表，存储街道边界GeoJSON与基础信息

- **community**：小区信息表，含房价、户数、所属街道、空间点位等字段

- **facility/facility\_category**：设施分类、设施信息表，存储七大类便民设施数据、平均分、开放时间、联系方式

- **evaluation**：用户评价表，记录用户评分、评价内容、审核状态、审核信息

- **favorite**：用户收藏表，支持多类型资源收藏管理

- **analysis\_plan**：分析方案表，持久化用户自定义空间分析方案

- **operation\_log**：操作日志表，记录全系统关键业务操作

内置两大核心存储过程：`sp_community_15min_stats`（15分钟设施分类统计）、`sp_calc_accessibility`（可达性加权评分计算），支撑核心空间分析能力。

## 🚀 项目部署运行

### 环境要求

- JDK 21、Maven 3\.9\+

- SQL Server 2022（开启TCP/IP服务，端口1433）

- VS Code \+ Live Server（前端运行）

- Python 3\.9\+（数据采集与清洗，可选）

### 运行步骤

1. **数据库初始化**：使用SSMS执行`init_db.sql`，自动创建数据库、数据表、视图、存储过程并导入真实POI数据

2. **后端启动**：导入backend Maven项目，配置数据库连接信息，启动SpringBoot服务，默认端口8080

3. **前端启动**：VS Code打开frontend目录，通过Live Server启动页面，完成地图加载与接口联调

4. **账号登录**：内置测试账号（admin/123456、operator/123456），区分权限访问
